Privacy Policy — AI Dev Coordinator

Last updated: October 14, 2026

Purpose

AI Dev Coordinator is a personal-use tool that exchanges development task files, status information, and results using the owner's Google Drive account.

Google data accessed

With the owner's authorization, the tool uses Google Drive API access to list, read, create, update, move, and delete files as required for the configured task handoff workflow. Its OAuth permission may technically permit access beyond the coordinator folder; operational access is intended for the coordinator's designated folders.

Use and sharing

Google Drive data is used to carry out the owner's requested development workflow. The tool does not sell Google user data or use it for advertising. Task files may be processed by development tools chosen and operated by the owner. This public website does not expose Drive data.

Storage and security

Task files and results are stored in the owner's Google Drive and local systems. OAuth credentials and tokens are stored in the owner's local Rclone configuration, not on this website. The owner controls access to those systems and can revoke authorization through Google Account settings.

Retention and deletion

Files are retained according to the owner's local and Google Drive workflow and may be deleted by the owner. Revoking OAuth access stops future authorized Drive access but does not automatically delete previously created files.

Contact

For questions, contact the repository owner through the project's GitHub repository.
